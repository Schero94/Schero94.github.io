KI und Infrastruktur

Slipstream

macOS-App für lokale LLMs

Slipstream ist eine macOS-App auf Basis eines llama.cpp-Forks, die die Expert-Gewichte von Mixture-of-Experts-Modellen von der SSD streamt, statt das ganze Modell in den Speicher zu laden. Ein Apple-Silicon-Mac mit 16 bis 36 GB kann so MoE-Coding-Modelle mit 35B bis 480B Parametern ausführen und über eine OpenAI-kompatible API auf 127.0.0.1:8080 bereitstellen.

Version v0.3.5 · Lizenz MIT

Dokumentation →GitHub

CloudDev AI

Selbst gehosteter KI-Workspace

CloudDev AI gibt einem Entwickler einen dauerhaften Workspace auf Railway: Browser-VS-Code, VS Code Remote-SSH und CloudCLI fürs Smartphone teilen einen Projektbaum, daneben laufen Forgejo, PostgreSQL und OmniRoute, das die CLIs von Codex und Claude Code an Modell-Provider weiterleitet. 17 von 24 Release-Gates sind erledigt; das Release im Railway Marketplace ist noch nicht fertig.

17 von 24 Release-Gates erledigt · Lizenz MIT

Fragen

Wer ist Schero D.?

Schero D. ist Projekt­manager, KI-Experte, Software­entwickler, Sysadmin und Produkt­entwickler in Berlin. Dies ist seine private Projekt­seite. Er veröffentlicht Open-Source-Arbeit auf GitHub als Schero94: Slipstream, CloudDev AI und acht Strapi-5-Plugins.

Arbeitet er mit lokalen LLMs und Coding-Agenten?

Ja. Slipstream führt Mixture-of-Experts-Coding-Modelle aus, die größer als der RAM eines Macs sind, indem es Expert-Gewichte von der SSD streamt. CloudDev AI ist ein selbst gehosteter Workspace, der Codex und Claude Code über OmniRoute leitet.

Wie bekomme ich passwortlosen Login in Strapi 5?

Mit Magic Link (strapi-plugin-magic-link-v5). Nutzer geben ihre E-Mail-Adresse ein, klicken den Link und erhalten eine normale Users-&-Permissions-Session. Ein E-Mail-Code oder eine Authenticator-App lässt sich als zweiter Faktor ergänzen.

Kann Strapi E-Mails über mehrere SMTP-Konten mit Failover senden?

Ja, mit Magic Mail. Es leitet jede Mail per Regel an ein Konto, hält stündliche und tägliche Kontingente ein und wechselt nur dann zum nächsten Konto, wenn der Provider die Mail nachweislich nicht angenommen hat.

Wie sehe und beende ich aktive Nutzer-Sessions in Strapi 5?

Magic Session Manager erfasst jede Anmeldung über Users & Permissions. Admins beenden einzelne oder alle Sessions eines Nutzers, und Nutzer erhalten Logout-Routen für ihre eigenen Geräte.

Kann Strapi 5 WhatsApp-, Telegram- oder SMS-Nachrichten senden?

Magic MessageGate sendet Template-Nachrichten über die offizielle WhatsApp Cloud API, die Telegram Bot API, seven.io oder Twilio, mit Zustell- und Lesestatus und Fallback auf SMS oder E-Mail.

Laufen die Plugins mit mehreren Strapi-Instanzen?

Ja. Sie halten geteilten Zustand in der Datenbank, daher laufen Railway-Replicas und pm2-Cluster-Worker auf einer PostgreSQL ohne Sticky Sessions. plugin-io braucht zusätzlich seinen Postgres- oder Redis-Adapter.

Sind die Plugins kostenlos?

Ja. Alle acht stehen unter MIT-Lizenz, ohne Lizenz­schlüssel, Stufen oder Telemetrie: Magic Link, Magic Mail, Magic Session Manager, Magic Mark, Auto UUID, Magic MessageGate, plugin-io und Magic Editor X.

Wo ist der Quellcode?

Jedes Projekt verlinkt sein GitHub-Repository. Alle liegen unter github.com/Schero94; plugin-io liegt in der Organisation strapi-community.
