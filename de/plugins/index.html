Strapi-5-Plugins

Acht Plugins für Strapi 5, jedes mit eigener Dokumentations­seite. Wähle nach dem Problem, das du lösen willst.

Welches Plugin brauche ich?

Wenn du das brauchstNimm
Login per E-Mail-Link oder Code, optional mit MFAMagic Link
Mehrere Mailkonten, Routing, Kontingente, FailoverMagic Mail
Eine Liste von Nutzer-Sessions, die du beenden kannstMagic Session Manager
Gespeicherte, geteilte Filter im Content ManagerMagic Mark
Eine serverseitig erzeugte UUID pro EintragAuto UUID
WhatsApp, Telegram oder SMS mit Zustell­statusMagic MessageGate
Live-Events zu Inhalten für dein Frontendplugin-io
Einen Blockeditor mit Live-Zusammen­arbeitMagic Editor X

Alle Plugins

  • Magic Linkstrapi-plugin-magic-link-v5

    Magic Link ist ein Strapi-5-Plugin für passwortlosen Login.

    v7.1.0Strapi ^5.24.0MIT, kostenlos

  • Magic Mailstrapi-plugin-magic-mail

    Magic Mail ist ein Strapi-5-Plugin, das jede Strapi-E-Mail über das passende Konto versendet.

    v4.5.0Strapi ^5.57.0MIT, kostenlos

  • Magic Session Managerstrapi-plugin-magic-sessionmanager

    Magic Session Manager ist ein Strapi-5-Plugin, das jede Anmeldung über Users & Permissions als Session erfasst.

    v4.13.0Strapi ^5.0.0MIT, kostenlos

  • Magic Markstrapi-plugin-magic-mark

    Magic Mark ist ein Strapi-5-Plugin, das Listenansichten im Content Manager als Lesezeichen speichert.

    v4.0.0Strapi ^5.57.0MIT, kostenlos

  • Auto UUIDstrapi-auto-uuid-v5

    Auto UUID ist ein Strapi-5-Custom-Field, das UUID-v4- oder v7-Werte auf dem Server erzeugt.

    v2.1.1Strapi ^5.24.0MIT, kostenlos

  • Magic MessageGatestrapi-plugin-magic-messagegate

    Magic MessageGate ist ein Strapi-5-Plugin, das Template-Nachrichten über WhatsApp, Telegram und SMS versendet.

    v1.1.0Strapi ^5.38.0MIT, kostenlos

  • plugin-io@strapi-community/plugin-io

    @strapi-community/plugin-io hängt einen Socket.IO-Server an Strapi 5 und sendet ein Event, sobald ein beobachtetes Dokument erstellt, geändert, veröffentlicht, zurückgezogen, sein Entwurf verworfen oder es gelöscht wird.

    v6.0.0Strapi ^5.38.0MIT, kostenlos

  • Magic Editor Xmagic-editor-x

    Magic Editor X ist ein Blockeditor für Strapi 5: ein Editor.js-Custom-Field mit Uploads in die Medienbibliothek, eigenen Blöcken, Versionsverlauf, Live-Zusammen­arbeit über mehrere Server und einem optionalen KI-Assistenten mit deinem eigenen Provider.

    v2.4.0Strapi ^5.38.0MIT, kostenlos
