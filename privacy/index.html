Privacy note

Last updated: 12 November 2026

Who runs this site

Schero D., Berlin. This is a private, non-commercial project page. My public work and profile are on GitHub.

Hosting

The site is a set of static files hosted on GitHub Pages. When you open a page, GitHub processes technical data such as your IP address in its server logs to deliver the page and to keep the service secure. I have no access to those logs. See the GitHub General Privacy Statement.

No forms, no cookies, no tracking

The site has no forms and collects no contact data. It sets no cookies and loads no analytics, advertising or social media code. Fonts, images and scripts come from this domain only. If you switch the colour theme, your choice is kept in your browser's local storage and never sent anywhere.

Links to other sites

Links to GitHub, npm and the plugin documentation lead to other sites with their own privacy terms.
