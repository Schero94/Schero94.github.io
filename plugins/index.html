Strapi 5 plugins

Eight plugins for Strapi 5, each with its own documentation site. Pick by the problem you have.

All plugins

  • Magic Linkstrapi-plugin-magic-link-v5

    Magic Link is a Strapi 5 plugin for passwordless login.

    v7.1.0Strapi ^5.24.0MIT, free

  • Magic Mailstrapi-plugin-magic-mail

    Magic Mail is a Strapi 5 plugin that sends every Strapi e-mail through the right account.

    v4.5.0Strapi ^5.57.0MIT, free

  • Magic Session Managerstrapi-plugin-magic-sessionmanager

    Magic Session Manager is a Strapi 5 plugin that records every sign-in through Users & Permissions as a session.

    v4.13.0Strapi ^5.0.0MIT, free

  • Magic Markstrapi-plugin-magic-mark

    Magic Mark is a Strapi 5 plugin that saves Content Manager list views as bookmarks.

    v4.0.0Strapi ^5.57.0MIT, free

  • Auto UUIDstrapi-auto-uuid-v5

    Auto UUID is a Strapi 5 custom field that generates UUID v4 or v7 values on the server.

    v2.1.1Strapi ^5.24.0MIT, free

  • Magic MessageGatestrapi-plugin-magic-messagegate

    Magic MessageGate is a Strapi 5 plugin that sends template messages over WhatsApp, Telegram and SMS.

    v1.1.0Strapi ^5.38.0MIT, free

  • plugin-io@strapi-community/plugin-io

    @strapi-community/plugin-io attaches a Socket.IO server to Strapi 5 and sends an event whenever a watched document is created, updated, published, unpublished, has its draft discarded or is deleted.

    v6.0.0Strapi ^5.38.0MIT, free

  • Magic Editor Xmagic-editor-x

    Magic Editor X is a block editor for Strapi 5: an Editor.js custom field with Media Library uploads, custom blocks, version history, live collaboration across several servers and an optional AI assistant that uses your own provider.

    v2.4.0Strapi ^5.38.0MIT, free
