AI and infrastructure

Slipstream

macOS app for local LLMs

Slipstream is a macOS app built on a fork of llama.cpp that streams Mixture-of-Experts expert weights from the SSD instead of loading the whole model into memory. A 16 to 36 GB Apple Silicon Mac can run 35B to 480B MoE coding models and serve them through an OpenAI-compatible API on 127.0.0.1:8080.

Version v0.3.5 · License MIT

Documentation →GitHub

CloudDev AI gives one developer a persistent workspace on Railway: browser VS Code, VS Code Remote-SSH and CloudCLI for the phone share one project tree, next to Forgejo, PostgreSQL and OmniRoute, which routes the Codex and Claude Code CLIs to model providers. 17 of 24 release gates are complete; the Railway Marketplace release is not ready yet.

Questions

Who is Schero D.?

Schero D. is a project manager, AI expert, software developer, sysadmin and product developer in Berlin. This is his private project page. He publishes open-source work on GitHub as Schero94: Slipstream, CloudDev AI and eight Strapi 5 plugins.

Does he work with local LLMs and coding agents?

Yes. Slipstream runs Mixture-of-Experts coding models larger than a Mac's RAM by streaming expert weights from the SSD. CloudDev AI is a self-hosted workspace that routes Codex and Claude Code through OmniRoute.

How do I add passwordless login to Strapi 5?

Install Magic Link (strapi-plugin-magic-link-v5). Users enter their e-mail address, click the link and get a normal Users & Permissions session. An e-mail code or an authenticator app can be added as a second factor.

Can Strapi send e-mail through several SMTP accounts with failover?

Yes, with Magic Mail. It routes each mail to an account by rules, keeps hourly and daily quotas, and moves to the next account only when the provider provably did not take the mail.

How do I see and end active user sessions in Strapi 5?

Magic Session Manager records every Users & Permissions sign-in. Admins end single sessions or all sessions of a user, and users get logout routes for their own devices.

Can Strapi 5 send WhatsApp, Telegram or SMS messages?

Magic MessageGate sends template messages through the official WhatsApp Cloud API, the Telegram Bot API, seven.io or Twilio, with delivery and read status and a fallback to SMS or e-mail.

Do the plugins work with several Strapi instances?

Yes. They keep shared state in the database, so Railway replicas and pm2 cluster workers on one PostgreSQL work without sticky sessions. plugin-io additionally needs its Postgres or Redis adapter.

Are the plugins free?

Yes. All eight are MIT licensed, without license keys, tiers or telemetry: Magic Link, Magic Mail, Magic Session Manager, Magic Mark, Auto UUID, Magic MessageGate, plugin-io and Magic Editor X.

Where is the source code?

Every project links its GitHub repository. All of them are on github.com/Schero94; plugin-io lives in the strapi-community organization.
